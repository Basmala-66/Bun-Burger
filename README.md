# Bun Burger

A responsive, front-end-only restaurant menu and ordering experience built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. Product photography and web fonts load from Unsplash and Google Fonts.

## Customize

- Edit the menu items, descriptions, prices, and images in `script.js`.
- Set the empty `WHATSAPP_PHONE` value in `script.js` to the restaurant's WhatsApp number, including the country code and without `+`, spaces, or punctuation. Checkout stays disabled until a valid number is configured.
- Update the display currency in `script.js` if the restaurant uses a different currency.

The cart is saved in the browser's local storage. Checkout opens WhatsApp with a pre-filled order; this project does not include a backend, payment processing, or delivery fee calculation.
